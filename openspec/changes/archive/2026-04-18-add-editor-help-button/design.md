## Context

当前任务编辑器缺乏引导，用户进入编辑器后不知道：
- 如何添加节点
- 如何连接节点
- 各类节点的作用
- 如何保存任务配置

## Goals / Non-Goals

**Goals:**
- 提供简洁的帮助对话框，快速引导用户上手
- 帮助内容结构清晰，分为"快速开始"和"节点说明"两部分
- 帮助内容可扩展，方便后续添加更多内容

**Non-Goals:**
- 不做复杂的交互式教程
- 不做视频或图片教程（纯文本）
- 不做多语言切换（当前中文）

## Decisions

### 1. 帮助内容存储格式

**决定**：使用 JSON 格式存储在 `public/help/editor-guide.json`

**理由**：
- JSON 易于解析，不需要额外 Markdown 解析库
- 结构化数据便于渲染成卡片或分栏
- 方便未来扩展字段（如图标、链接等）

### 2. 帮助对话框 UI

**决定**：新建 `EditorHelpDialog.vue` 组件，与 `ExampleQuestsDialog` 风格保持一致

**理由**：
- 复用现有的对话框样式
- 用户已经熟悉这种弹窗交互

### 3. 帮助内容结构

```json
{
  "quickStart": {
    "title": "快速开始",
    "steps": ["从左侧拖拽节点到画布", "点击节点连接点并拖拽到另一个节点", "点击节点后在右侧面板编辑属性", "点击保存按钮保存配置"]
  },
  "nodeTypes": [
    { "type": "start", "name": "开始节点", "desc": "任务的入口点，每个任务有且只有一个开始节点" },
    { "type": "task", "name": "任务节点", "desc": "定义具体的任务目标，如杀怪、采集物品等" },
    ...
  ]
}
```

## Risks / Trade-offs

- **帮助内容不够详细** → 未来可扩展更多节点说明或添加"更多帮助"链接
- **内容与实际功能不一致** → 每次编辑器更新时需同步更新帮助文档
