- 存储
  - mysql+sqlite+json
- 任务格式

```yaml
task1: # 任务名称
  type: # 任务类型
  target: # 任务目标
  reward: # 任务奖励
```

- 任务类型：
  - 周期任务
  - 长期任务
  - 触发任务（拓展功能）

- 任务目标

  - 合成
  - 挖掘
  - 垂钓
  - 放置
  - 消耗
  - 击杀
  - 附魔
  - 剪刀
  - 繁殖
  - 驯服
  - ...

- 任务奖励

  - 支持payerpotion、item（物品）、vault、xp、
  -
