# 网页编辑器 - 三大模块完善设计

## 概述

完善奖励库、玩家进度、统计管理三个前端页面，采用现代化卡片+表格风格。

## 奖励库 (RewardLibraryView)

### 布局
- 顶部：标题 + "新建模板" 按钮
- 主体：响应式卡片网格（1-4列自适应）
- 每张卡片显示：名称、类型图标、值、操作按钮

### 卡片设计
```
┌─────────────────────────────┐
│  ⚔️ 剑士装备包              │
│  物品 | 数量: 10            │
│  ──────────────────────    │
│  [编辑] [删除]              │
└─────────────────────────────┘
```

### 类型图标
- item → 📦
- xp → ⭐
- money → 💰
- command → ⚡

### 功能
- 新建/编辑 → 模态框表单
- 删除 → 确认对话框
- 刷新列表

## 玩家进度 (PlayerProgressView)

### 布局
- 顶部：搜索框 + 状态下拉筛选
- 主体：数据表格 + 分页器

### 表格设计
| 玩家 | 任务ID | 状态 | 操作 |
|------|--------|------|------|

- 状态显示为彩色标签（未开始灰色/进行中蓝色/已完成绿色）
- 操作：查看详情（展开行显示更多进度信息）

### 功能
- 搜索（玩家UUID/ID模糊匹配）
- 状态筛选
- 分页（每页20条）
- 刷新

## 统计面板 (StatisticsView)

### 布局
- 顶部：时间范围切换（7天/30天）
- 主体：2x2 网格布局
  - 完成率饼图（左上）
  - 活动趋势折线图（右上）
  - 摘要卡片 x2（下方）

### 摘要卡片
```
┌──────────────────────┐
│  总完成任务          │
│       1,234          │
│     ↑ 12% vs上周     │
└──────────────────────┘
```

### 图表库
使用 Chart.js 或 Apache ECharts（轻量、Vue 集成好）
